# Hack-Computer
This repository showcases the creation of a modern computer from basic logic gates to a fully functional architecture, using HDL and tested on a hardware simulator.

# Hack Computer Implementation

In this repository, I implement the Hack computer under the guidance of the nand2tetris course. The learning process took place through the course website [nand2tetris.org](https://www.nand2tetris.org/) and through CampusIL. The course was developed by Professor Noam Nisan and Professor Shimon Schocken. For more information about the course, please refer to the course website.

Additionally, the creators of the course developed a simulator for running HDL files and provided test files. A guide on how to use the software can be found in the `software package.pdf` file as well as on the course website.

The implementation of the projects can be found in the different folders under: Simulator Files -> nand2tetris -> projects -> <index>

## Project Overview

This project involves building a modern computer from scratch, starting with basic logic gates and culminating in a fully functional architecture capable of running any program. The hardware components (chips) are developed using Hardware Description Language (HDL), which is learned and applied throughout the course. These hardware designs are tested and executed on a hardware simulator provided by the course.

The main topics covered include:

- **Basic Logic Gates:** Construction of basic logic gates (XOR, AND, OR, etc.) and their applications in building more complex components.
- **Arithmetic Logic Unit (ALU):** Design and implementation of an ALU that performs arithmetic and logical operations using the basic gates created earlier.
- **Memory Units:** Building registers, RAM, and ROM using flip-flops and other components, and understanding how they are used to store data in a computer.
- **Machine Language & Assembly:** Writing machine-level programs, converting symbolic representations into binary code, and running programs in assembly language.
- **Computer Architecture & CPU:** Designing a CPU and a complete computer system capable of running programs written in the assembly language.
- **Assembler Development:** Creating a tool to translate assembly programs into machine code, including syntax parsing, code generation, and symbol table management.

Through this repository, you can explore the step-by-step implementation of the Hack computer, from simple logic gates to the final fully functioning architecture.
